# Run Windhill locally

Requires Python 3. Extract this ZIP, open a terminal in windhill-pawn-rpg, and run:

```sh
python -m http.server 8000 --directory dist
```

Open http://localhost:8000 in your browser. On macOS/Linux you may need python3 instead of python.

Includes editable HTML, CSS, JavaScript, optimized game artwork, fonts, and asset scripts. Large original generation images and hosting metadata are excluded. Asset scripts that require original generation images need those inputs supplied separately.
